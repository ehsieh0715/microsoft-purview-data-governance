# Microsoft Purview Data Governance for Energy Data

A portfolio project demonstrating the implementation of enterprise data governance practices using Microsoft Purview for a simulated energy provider.

## Project Objectives

This project demonstrates how Microsoft Purview can be used to establish governance across key energy business data domains, including:

- Customer
- Billing
- Metering
- Tariff

The implementation covers:

- Data cataloguing and metadata management
- Business glossary management
- Data ownership and stewardship
- Data classification and sensitive data identification
- Data quality monitoring
- Data issue remediation and escalation
- Governance KPI reporting
- GDPR-aligned governance practices

## Business Scenario

The simulated organisation supplies electricity and gas to residential and commercial customers.

Data is distributed across customer, billing, metering, and tariff datasets. The organisation requires a governance framework to improve data discoverability, establish consistent business definitions, assign accountability, monitor data quality, and manage sensitive customer information.

## Data Domains

| Domain | Description |
|---|---|
| Customer | Customer identity, contact and account information |
| Billing | Customer invoices and payment information |
| Metering | Meter readings and energy consumption |
| Tariff | Electricity and gas pricing plans |
